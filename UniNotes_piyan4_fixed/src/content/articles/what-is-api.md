# 什麼是 API？用生活例子看懂

API（應用程式介面）是讓不同程式互相溝通的規則。

## 餐廳點餐的比喻

你是使用者，廚房是伺服器，服務生就是 API：你不需要進廚房，只要照菜單點餐，服務生會把餐點送來。

## API 如何運作

### 請求與回應

程式送出「請求」，伺服器回傳「回應」，常見格式為 JSON。

```json
{ "city": "Taipei", "temperature": 24 }
```

### 常見用途

- 查詢天氣資料
- 使用第三方登入
- 串接 AI 服務

## 延伸學習

試著找一個免費的公開 API，用瀏覽器開啟網址，觀察回傳的資料。
